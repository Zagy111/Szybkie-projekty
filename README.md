# Szybkie projekty

Zwykłe proste projekty, które służą mi do nauki :D

## Rozkład plików

```text
Szybkie-projekty/
├── generator-hasel.py          # Generator losowych haseł
├── minigame.cpp                # Prosta gra terminalowa
├── rps.py                      # Gra w kamień, papier, nożyce
├── twierdzenie-pitagorasa.cpp  # Obliczanie przeciwprostokątnej
├── zgadywanie.py               # Gra w zgadywanie liczby
├── REMEMER.md                  # Notatki do nauki C++
└── README.md                   # Opis repozytorium
```

## Co robią projekty?

- **generator-hasel.py** – generuje hasło o podanej długości; można włączyć cyfry i znaki specjalne. Używa modułu `random`, więc nie jest przeznaczony do tworzenia bezpiecznych haseł.
- **minigame.cpp** – gra w terminalu, w której poruszasz się po planszy, omijasz przeszkody, zbierasz monetę i walczysz z przeciwnikiem, żeby dotrzeć do końca.
- **rps.py** – gra w kamień, papier, nożyce przeciwko komputerowi.
- **twierdzenie-pitagorasa.cpp** – oblicza długość przeciwprostokątnej na podstawie dwóch przyprostokątnych.
- **zgadywanie.py** – losuje liczbę od 1 do 100. W trybie normalnym liczba prób jest nieograniczona, a w trudnym masz ich siedem.
- **REMEMER.md** – notatki i przykłady kodu C++ do zapamiętania.
